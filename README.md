# Contextualização e Objetivos gerais
O crescimento dos aplicativos de delivery transformou a forma como consumidores interagem com restaurantes e estabelecimentos comerciais. Atualmente, essas plataformas atuam como intermediadoras entre oferta e demanda, registrando uma grande quantidade de informações sobre o perfil dos usuários e seus hábitos de consumo.
Nesse cenário, compreender os fatores que influenciam a decisão de um cliente realizar um pedido torna-se uma vantagem estratégica. Esse conhecimento permite direcionar campanhas comerciais, personalizar ofertas e melhorar a experiência dos usuários, contribuindo para o aumento das taxas de conversão e satisfação dos clientes.

O objetivo deste trabalho é identificar quais características dos consumidores possuem maior influência sobre a realização de pedidos de delivery e sobre a probabilidade de geração de avaliações positivas, utilizando técnicas de engenharia de dados e aprendizado de máquina.
