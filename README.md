# data_engineering_mvp
Contextualização e Objetivos gerais
O mercado de delivery passou por uma profunda transformação com o surgimento dos aplicativos de entrega, que atuam como plataformas de conexão entre consumidores e estabelecimentos comerciais. Ao centralizar a oferta de produtos e serviços em um único ambiente digital, essas plataformas tornaram-se indispensáveis no cotidiano de milhões de usuários ao redor do mundo.
Nesse contexto altamente competitivo, compreender o comportamento dos consumidores tornou-se um fator estratégico para as empresas do setor. Identificar quais características dos clientes possuem maior influência na decisão de realizar ou não um pedido permite direcionar ações de marketing, personalizar ofertas e aprimorar a experiência do usuário.
Dessa forma, este trabalho tem como objetivo conduzir uma análise de dados aplicada a uma base pública relacionada ao mercado de delivery, utilizando técnicas de engenharia de dados e aprendizado de máquina para identificar e mensurar os fatores que mais influenciam a decisão de compra dos consumidores. Ao final do processo, esses fatores serão classificados de acordo com seu grau de importância para o resultado analisado.
Para o desenvolvimento do estudo, serão utilizados dados públicos de consumidores e pedidos de delivery na Índia. Embora a base de dados esteja associada a esse mercado específico, a metodologia proposta foi concebida de forma genérica, permitindo sua replicação e adaptação para outros contextos, incluindo o mercado brasileiro.
